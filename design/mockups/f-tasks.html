Store tasks · built for the shop floor

Works with one hand, gloves on, in a back room with no signal.

  1. Offline is a normal stateA clear, high-contrast banner says what is saved on the phone. Nothing is lost and nothing gets stuck. Each item shows "Saved" until it syncs.Fixes: flaky connection in store (P4)
  2. Three simple filtersToday, This week and Done, with counts. No folders or settings to learn.Fixes: too many tasks (P1)
  3. Grouped by deadline, with time estimatesEach task shows where it came from (mission, HQ campaign or routine), who owns it and how long it takes. Large tick boxes, with the task name in the accessible label.Fixes: unclear why, task overload (P1, P2)
  4. Answer in a few tapsYes/No as 56 px buttons, then quick-pick answers. On mobile this is a full screen that opens from the list. On desktop it sits beside the list.Fixes: slow data entry (P3)
  5. Pick, don't typeCommon answers are buttons. "Other" opens voice or text, so the keyboard is a last resort.Fixes: slow data entry (P3)
  6. Photo and voice as evidenceProof of work that actually happened, instead of a tick for a display that hasn't arrived. Uploads wait and retry on their own.Fixes: tick-box compliance (P3, P6)
  7. Shows how this links to the missionThe task explains what happens next, including that a broken machine pauses the mission so the store isn't blamed.Fixes: the gap between HQ and stores, trust in impact numbers (P5, P6)
